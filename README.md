# Saturday Receipt

Pilot. One job:

**Show me what I actually saved this week, in dollars, on things I already buy.**

Groceries and fuel. Perth / WA first. No club. No token. No bank login.

Open `index.html` or the live deploy. Everything stays in the browser.

## What a dollar is

A line only counts with:

1. A purchase you made
2. A price you paid
3. A documented better number that existed that day
4. A source and a date

Two columns: **captured** (you took it) and **missed** (a sourced cheaper option sat unused). Unknown is not zero.

## Pilot

- Eight households
- Four Saturday–Friday weeks
- No fee
- Fuel better-price from [FuelWatch](https://www.fuelwatch.wa.gov.au)

Demo week is labelled DEMO. It is not anyone’s money.

## Stack

Static HTML. No build. No server. `localStorage` only.
